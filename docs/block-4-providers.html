Providers — secret boundary

15 min 5L / 10HO 2:55 – 3:10
Slide 1 / 3 · The setup pattern

Where provider keys live in production

  • Bifrost holds your provider keys
  • Your app holds the Bifrost URL
  • Provider keys never leave the gateway
  • Compliance reviewers love this
Slide 2 / 3 · Anti-patterns

Where keys do NOT live

  • Your Vue runtime
  • Your server .env that ships with deploys
  • Your CI secrets bundle
  • Sticky note on the monitor

The gateway is the secret boundary.

Slide 3 / 3 · Five clicks to provider configured

HO #1 — Set up providers (10 min)

  1. Sidebar → Models → Model Providers
  2. Click Add Provider
  3. Select Anthropic → paste API key → save
  4. Repeat for OpenAI
  5. (Optional, AWS-equipped) Add Bedrock with AWS creds
Speaker notes

Slide 1 — the pattern: "Bifrost holds your provider keys. Your app holds the Bifrost URL. The provider keys — Anthropic, OpenAI, Bedrock — never leave the gateway. If you're audited tomorrow and asked 'where do your AI credentials live?', the answer is 'in the gateway, behind RBAC.' That's a defensible answer. 'They're in our Vue server's .env' is not."

Slide 2 — kill the anti-patterns: "Provider keys do not belong in your Vue runtime. They do not belong in your server .env that ships with deploys. They do not belong in your CI secrets bundle. The gateway is the secret boundary."

Slide 3 — set the HO: "Five clicks. Sidebar to Model Providers. Add provider, select Anthropic, paste your key. Save. Repeat for OpenAI. If you have AWS credentials and you've requested Bedrock model access, add Bedrock as a third. Ten minutes. I'll loop the room."

During HO: loop the room. Watch for red provider status — usually billing not enabled on the API key. Send those attendees to back-of-room helper.

Demo piece — Attendees

Bifrost dashboard is already open from Beat 4.1.3's boot. If your tab 404s, refresh — give it 5s. Click sequence:

  1. Sidebar → Models → Model Providers
  2. Add Provider → Anthropic → paste ANTHROPIC_API_KEY from .env → Save
  3. Add Provider → OpenAI → paste OPENAI_API_KEY from .env → Save
  4. (Optional) Add Provider → Bedrock → AWS access key + secret → Save

Instructor mirror: project the same flow once on the screen. Wait for green status on each provider before moving on.

Common gotchas:

  • Provider key validation may take a moment — green status appears in 5–15s
  • Red status → check billing is enabled on the provider account
  • Corporate VPN blocking api.anthropic.com or api.openai.com → hop to a hotspot
